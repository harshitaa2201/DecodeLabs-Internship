# 🤖 Nova AI - Rule-Based AI Chatbot

## 📌 Project Description

<p align="center">
  <img src="banner.png" alt="Nova AI Banner" width="100%">
</p>

Nova AI is a simple rule-based chatbot developed in Python as part of **DecodeLabs Artificial Intelligence Project 1**.

The chatbot responds to predefined user inputs using **if-elif-else statements** and runs continuously until the user chooses to exit. It demonstrates basic AI concepts, decision-making logic, control flow, and user interaction.

---

## 🎯 Objective

- Build a rule-based AI chatbot.
- Handle greetings and exit commands.
- Use if-elif-else decision-making.
- Keep the chatbot running using a continuous loop.
- Respond to predefined user inputs.

---

## ✨ Features

- 👋 Personalized greeting using the user's name
- 🤖 Introduces itself as Nova AI
- 💬 Handles greetings
- 🧠 Explains Artificial Intelligence
- 📚 Lists applications of AI
- 🙋 Remembers the user's name
- 👨‍💻 Tells who created the chatbot
- 😂 Tells a programming joke
- 💡 Shares a fun fact
- 💪 Provides motivation
- 🙏 Responds to "Thank You"
- 📖 Displays a help menu with all available commands
- 🚪 Ends the conversation using "bye" or "exit"
- ❓ Handles unknown inputs gracefully

## ▶️ How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python chatbot.py
```

5. Start chatting with Nova AI.
